# 🎓 Campus Connect

Campus Connect is a robust Learning Management System (LMS) designed to streamline academic resource sharing and enhance student learning through AI-powered tools. It serves as a centralized hub where students can access study materials, take automated quizzes, and track their academic progress on a gamified leaderboard.

* * *

## 🚀 Key Features

### 🔐 Security & Access

  * **Role-Based Access Control:** Secure authentication for Students (via USN), Teachers, and Admins.
  * **Subscription Model:** Freemium architecture with **Razorpay integration** (Test Mode) to unlock premium AI features.



### 📚 Academic Resources

  * **Centralized Study Material:** Hierarchical browsing (Branch → Semester → Subject → Module) to easily find specific notes.
  * **Advanced PDF Viewer:** In-app PDF viewing with split-screen mode for simultaneous reading and AI chatting.



### 🤖 AI-Powered Learning (Gemini Integration)

  * **Auto-Summarizer:** Instantly generates concise summaries of PDF notes.
  * **Quiz Generator:** Automatically creates 5-question quizzes from any uploaded document.
  * **Chat with PDF:** Interactive Q&A with study materials using context-aware AI.



### 🏆 Gamification

  * **Leaderboards:** Real-time ranking of students based on quiz performance.
  * **Badges:** Earn Gold, Silver, and Bronze badges for high scores.



### 🛠️ Management

  * **Teacher & Admin Dashboards:** Dedicated interfaces for managing users, uploading content, and resetting semester data.



* * *

## 💻 Tech Stack

Layer | Technologies  
---|---  
**Frontend** | React.js, CSS3 (Custom responsive design)  
**Backend** | Node.js, Express.js  
**Database** | MongoDB (Atlas)  
**AI Engine** | Google Gemini API  
**Auth** | JWT (JSON Web Tokens)  
**File Handling** | Multer, PDF-Lib  
**Payments** | Razorpay (Test Mode)
